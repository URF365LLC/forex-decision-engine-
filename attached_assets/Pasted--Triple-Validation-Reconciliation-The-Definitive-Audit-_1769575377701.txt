### 2. Stop Logic Creates Widow-Maker Trades

**All Three Audits Flagged:**
```typescript
const stopLossPrice = Math.min(signalBar.low, ema55Signal!) - (atrSignal! * 0.5);
```

**Unanimous Problem:**
- When EMA55 is far below signal bar (common in strong trends)
- Stop anchors to distant EMA55 instead of actual structure
- Creates 80-100 pip stops on 40-pip targets

**Example All Audits Agree On:**
```
Signal bar low:  1.0840
EMA55:          1.0800 (40 pips below)
Stop:           1.0795 (Math.min chooses 1.0800 - 5 pips)
Entry:          1.0870 (next bar open)
Stop distance:  75 pips
TP target:      40 pips
RR:            0.53 (not 2.0!)
```

**Consensus Fix:**
```typescript
// Use actual structure, not EMA55
const structuralStop = direction === 'long'
  ? signalBar.low - (atrSignal * 0.5)
  : signalBar.high + (atrSignal * 0.5);

// Sanity cap: don't exceed 2.5 ATR
const stopDistance = Math.abs(entryPrice - structuralStop);
const maxStop = atrSignal * 2.5;

if (stopDistance > maxStop) {
  return null; // Pullback too deep, skip
}

const stopLossPrice = structuralStop;
```
