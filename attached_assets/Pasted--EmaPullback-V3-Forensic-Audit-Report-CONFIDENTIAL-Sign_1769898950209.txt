## 4. Entry Timing — Next-Bar-Open Risk/Reward Compression

Signal fires on `bars[length-2]` (signal bar close). Execution is at `bars[length-1].open` (next bar open). On H1 this is a 0–60 min gap. Trend-continuation tolerates this better than mean-reversion (confirmed by Maven Securities alpha-decay research), but the gap still compounds with the gate defects above to degrade realized RR in specific failure modes.

### Theoretical vs. Realized RR — Numeric Example

| Metric | Backtest (Bar Close) | Live (Next Bar Open) |
|--------|---------------------|---------------------|
| Entry Price | 1.08550 (exact zone) | 1.08700 (+15 pip gap) |
| Stop Loss | 1.08350 (zone – 0.5 ATR) | 1.08350 (anchored to signal) |
| Risk (pips) | 20 pips | 35 pips (+75%) |
| Take Profit | 1.08950 (2R = 40 pips) | 1.08950 (fixed target) |
| Reward (pips) | 40 pips | 25 pips (–37.5%) |
| Realized RR | 2.00 | 0.71 |

**Gate 7 (Entry Bar EMA200 Validation) is the targeted fix.** It does not eliminate the next-bar gap — that is architecturally inherent — but it **vetoes entries where price has crossed back through EMA200 between signal and execution**, which is the specific failure mode that converts valid signals into counter-trend entries with collapsed RR.

### GATE 1: H4 Trend Must Exist [CRITICAL]

**Source Lines:** Line 214  
**Expected Block Rate:** 30–40% of false signals  
**Root Cause:** Line 214: `if (preflight.h4Trend)` wraps the entire counter-trend block. When `h4Trend` is undefined (stale/missing H4 data), the entire block is skipped silently. No trend context = trading blind.

#### V3 — VULNERABLE

```typescript
// L213–223: H4 TREND BLOCK
if (preflight.h4Trend) {          // ← undefined = skipped!
  const trendAdj = getTrend...;
  confidence += trendAdj;
  if (isTrendAligned(...)) {
    // aligned — continues
  } else { return null; }
}
// Falls through → trades with no H4
```

#### V3.1 — GATED

```typescript
// V3.1 GATE 1: HARD REQUIRE
if (!preflight.h4Trend) {
  logger.warn('GATE1_BLOCKED',
    { symbol });
  return null;  // ← hard stop
}
// h4Trend guaranteed below
if (!isTrendAligned(
  preflight.h4Trend, direction))
  return null;
```

#### False Signal Scenario

```
EUR/USD Asian session — H4 last update 14h ago
preflight.h4Trend = undefined
V3:  H4 block skipped entirely → signal fires
V3.1: GATE 1 → return null before any scoring
```

### GATE 2: H4 ADX ≥ 20 [CRITICAL]

**Source Lines:** Lines 214–223 (nested)  
**Expected Block Rate:** 10–15% of false signals  
**Root Cause:** Even when `h4Trend` exists, its `adxValue` is never read anywhere in V3. A stale H4 trend with ADX 12–19 passes alignment and grants the full trend confidence adjustment, but the macro timeframe has zero directional momentum.

#### V3 — VULNERABLE

```typescript

if (preflight.h4Trend) {
  // h4Trend.adxValue NEVER read
  const trendAdj =
    getTrendConfidenceAdj(
      preflight.h4Trend, dir);

}
```

#### V3.1 — GATED

```typescript
// V3.1 GATE 2: H4 ADX FLOOR
// (after Gate 1 confirms h4Trend exists)
if (preflight.h4Trend.adxValue < 20) {
  logger.warn('GATE2_BLOCKED',
    { symbol,
      h4Adx: preflight.h4Trend
              .adxValue });
  return null;
}
```

#### False Signal Scenario

```

V3:  trades with +15 trend bonus
V3.1: GATE 2 → return null (16.4 < 20)
```

### GATE 4: EMA Zone Width ≤ 3 ATR [HIGH]

**Source Lines:** Lines 79–81  
**Expected Block Rate:** 5–10% of false signals  
**Root Cause:** Lines 79–81 define the pullback zone as max/min of EMA20/50 with no constraint on spread. In ranging markets EMA20 and EMA50 diverge — zones can span 60–100 pips. Any price inside this band triggers 'inPullbackZone'. Detection of 'price exists in range' — not 'price pulled back'.

#### V3 — VULNERABLE

```typescript
// L79–81: NO WIDTH CONSTRAINT
const emaZoneHigh =
  Math.max(ema20Signal!, ema50Signal!);
const emaZoneLow =
  Math.min(ema20Signal!, ema50Signal!);
const inPullbackZone =
  signalBar.low <= emaZoneHigh &&
  signalBar.high >= emaZoneLow;
// 70-pip zone → always true
```

#### V3.1 — GATED

```typescript
// V3.1 GATE 4: ZONE WIDTH CHECK
const zoneWidth = Math.abs(
  ema20Signal! - ema50Signal!);
if (zoneWidth > atrSignal! * 3) {
  logger.warn('GATE4_BLOCKED',
    { symbol, widthAtr:
      (zoneWidth/atrSignal!)
        .toFixed(2) });
  return null;
}
```

#### False Signal Scenario

```
EUR/USD sideways channel
EMA20=1.08500  EMA50=1.07800  → 70pip zone
ATR = 16.7 pips  → zone = 4.2 ATR
V3:  'inPullbackZone' fires
V3.1: GATE 4 → return null (4.2 > 3.0)
```

### GATE 7: Entry Bar EMA200 Check [HIGH]

**Source Lines:** Line 226  
**Expected Block Rate:** 5–10% of false signals  
**Root Cause:** Line 226: `entryPrice = entryBar.open` with no re-validation against EMA200. Signal bar validates trend (close > EMA200) but between signal close and next bar open, price can gap through EMA200. The entry is now counter-trend with no check. This is the primary bar-open/close timing defect.

#### V3 — VULNERABLE

```typescript
// L226: NO ENTRY RE-VALIDATION
const entryPrice = entryBar.open;
// Signal bar: close > ema200 ✓
// Entry bar:  open  < ema200 ✗
// → counter-trend long, undetected

// Proceeds directly to stop/TP calc
```

#### V3.1 — GATED

```typescript
// V3.1 GATE 7: ENTRY VALIDATION
const entryPrice = entryBar.open;
const ema200Entry =
  atIndex(ema200, entryIdx);
if (!ema200Entry) return null;

if (direction === 'long'
    && entryPrice < ema200Entry) {
  logger.warn('GATE7_BLOCKED',
    { symbol, entryPrice,
      ema200: ema200Entry });
  return null;
}
```

#### False Signal Scenario

```
Signal bar 17:00: close = 1.08550
EMA200 @ signal: 1.08500 → above ✓
Entry bar 18:00: open  = 1.08470
EMA200 @ entry:  1.08490 → below ✗
V3:  long entry below EMA200 → RR collapse
V3.1: GATE 7 → return null (crossed back)
```

## 6. RSI Reset Quality — Phase 2 Enhancement

Lines 110–112 / 158–160: RSI neutral bonus fires when `rsiSignal >= 40 && rsiSignal <= 60`. This 20-point band is 'RSI is not extreme', not 'RSI has reset from an extreme'. In choppy markets RSI oscillates in this band continuously. Phase 2 tightens to 45–55 and requires RSI was below 35 (long) or above 65 (short) within the prior 2 bars.

### V3 — Wide Band, No History

```typescript
// L109–112: WIDE BAND, NO HISTORY
if (rsiSignal! >= 40
    && rsiSignal! <= 60) {
  confidence += 10;
}
// RSI=52 for 10 bars → fires every time
```

### V3.1 Phase 2 — Actual Reset Check

```typescript
// PHASE 2: ACTUAL RESET CHECK
const rsiPrev =
  atIndex(rsi, signalIdx - 1);
const rsiPrev2 =
  atIndex(rsi, signalIdx - 2);
const wasExtreme =
  direction === 'long'
    ? (rsiPrev!<35 || rsiPrev2!<35)
    : (rsiPrev!>65 || rsiPrev2!>65);
const nowNeutral =
  rsiSignal!>=45 && rsiSignal!<=55;
if (wasExtreme && nowNeutral)
  confidence += 10;
```
