### ✅ Clarification 2 — EMA200 Filter Placement

**Place EMA filter after:**

```ts

```

…and **before** H4 trend adjustments.

That guarantees:

* direction exists
* you don’t mix “market context hard gates” with “trend scoring” logic

**Code block:**

```ts
// EMA200 DIRECTION FILTER (required indicator must be used)
if (direction === 'long' && emaSignal != null && signalBar.close <= emaSignal) return null;

  triggers.push('Above EMA200 (momentum context)');
  reasonCodes.push('EMA_BULLISH_STACK');
```
