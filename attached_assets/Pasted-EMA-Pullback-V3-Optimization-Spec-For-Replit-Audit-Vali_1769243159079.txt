🔴 CRITICAL #1: ADX Unconditional +15 (Lines 79-80, 92-93)
Current Code:

confidence += 15;
triggers.push(`Strong trend (ADX: ${adxSignal!.toFixed(1)})`);

Problem: Fires unconditionally. ADX = 12 (choppy) gets labeled "Strong trend" and +15 confidence.

Impact: Confidence inflation, weak-trend pullbacks pass threshold.

Fix: Tiered scoring:

if (adxSignal! >= 35) {
  confidence += 15;
  triggers.push(`Very strong trend (ADX: ${adxSignal!.toFixed(1)})`);
} else if (adxSignal! >= 25) {
  confidence += 10;
  triggers.push(`Strong trend (ADX: ${adxSignal!.toFixed(1)})`);
} else if (adxSignal! >= 18) {
  confidence += 5;
  triggers.push(`Moderate trend (ADX: ${adxSignal!.toFixed(1)})`);
} else {
  triggers.push(`Weak trend (ADX: ${adxSignal!.toFixed(1)})`);
  // No bonus - weak trend pullbacks are risky
}

🔴 CRITICAL #2: Weak Candle Confirmation (Lines 84, 97)
Current Code:

if (signalBar.close > signalBar.open) { 
  confidence += 10; 
  triggers.push('Bullish candle confirmation'); 
  reasonCodes.push('CANDLE_CONFIRMATION'); 
}

Problem: Measures candle COLOR, not QUALITY. A +1 pip close counts as "bullish."

Fix: Close-in-range (0.7/0.3):

const range = signalBar.high - signalBar.low;
const closeRatio = range > 0 ? (signalBar.close - signalBar.low) / range : 0.5;

if (direction === 'long' && closeRatio > 0.7) {
  confidence += 15;
  triggers.push('Strong close (top 30% of range)');
  reasonCodes.push('CANDLE_CONFIRMATION');
}
if (direction === 'short' && closeRatio < 0.3) {
  confidence += 15;
  triggers.push('Strong close (bottom 30% of range)');
  reasonCodes.push('CANDLE_CONFIRMATION');
}

🔴 CRITICAL #3: Missing EMA50 Reclaim Bonus (Conditional)
Current: No differentiation between shallow (EMA20) and deep (EMA50) pullbacks.

Fix: Add conditional bonus when EMA50 is touched AND reclaimed:

// EMA50 reclaim - only if price actually touched EMA50

  confidence += 10;
  triggers.push('Deep pullback with EMA50 reclaim');
}
if (direction === 'short' && signalBar.high >= ema50Signal! && signalBar.close < ema50Signal!) {
  confidence += 10;
  triggers.push('Deep pullback with EMA50 reclaim');
}
