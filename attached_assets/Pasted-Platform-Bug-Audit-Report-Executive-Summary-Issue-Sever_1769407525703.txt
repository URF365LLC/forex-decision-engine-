5. /src/server.ts
Purpose: Express API server

Bug Found: /api/signals endpoint didn't return total count, limiting pagination accuracy

Root Cause: Response only included count: signals.length (fetched subset), not total database count

Fix Applied (lines 478-507):

app.get('/api/signals', validateQuery(SignalsQuerySchema), async (req, res) => {
  const { limit, offset, grade, symbol } = req.query;
  const pageOffset = offset ?? 0;

  let signals;
  let total;

  if (grade) {
    signals = await signalStore.getByGrade(grade, limit);
    total = signals.length;
  } else if (symbol) {
    signals = await signalStore.getBySymbol(symbol.toUpperCase(), limit);
    total = signals.length;
  } else {
    signals = await signalStore.getRecent(limit, pageOffset);
    total = await signalStore.getTotal(); // NEW: Get actual total
  }

  res.json({
    success: true,
    count: signals.length,
    total,       // NEW
    offset: pageOffset,  // NEW
    limit,
    signals
  });
});

Side Effects: None - backward compatible (adds new fields)

6. /src/storage/signalStore.ts
Purpose: Signal persistence (PostgreSQL + JSON fallback)

Bug Found: No method to get total signal count; getRecent didn't support offset

Root Cause: Only limit-based fetching was implemented

Fix Applied:

New getTotal() method (lines 369-381):

async getTotal(): Promise<number> {
  if (isDbAvailable()) {
    const db = getDb();
    const result = await db
      .selectFrom('signals')
      .select(db.fn.countAll().as('count'))
      .executeTakeFirst();
    return Number(result?.count ?? 0);
  }
  return this.signals.length;
}

Updated getRecent() (lines 383-405):

async getRecent(limit: number = 50, offset: number = 0): Promise<StoredSignal[]> {
  if (isDbAvailable()) {
    const rows = await db
      .selectFrom('signals')
      .selectAll()
      .orderBy('created_at', 'desc')
      .limit(limit)
      .offset(offset)  // NEW
      .execute();
    return rows.map(row => this.rowToStoredSignal(row));
  }
  return this.signals
    .slice()
    .sort((a, b) => new Date(b.created_at).getTime() - new Date(a.created_at).getTime())
    .slice(offset, offset + limit);  // NEW
}

Side Effects: None - backward compatible
