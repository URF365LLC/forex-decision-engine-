## 🟡 MEDIUM PRIORITY: Where We Diverge

### Stop Placement Logic

**My Take (Critical):**
```typescript
// Current: Uses Math.min(signalLow, ema55) which can be way too wide
const stopLossPrice = Math.min(signalBar.low, ema55Signal!) - (atrSignal! * 0.5);

// Problem: If EMA55 is 50 pips below signal bar, stop is massive
// This creates risk/reward distortion
```

**GPT's Take (Acceptable):**
> "Decent but not pure invalidation... If EMA55 is far from action, can widen stops unexpectedly"

**Difference:** I see this as high-impact (explains why strategy has mediocre RR despite 2:1 target). GPT sees it as nuance.

**Reconciled Fix:**
```typescript
// Use signal bar structure, not EMA55
const structuralStop = direction === 'long'
  ? signalBar.low - (atrSignal * 0.5)
  : signalBar.high + (atrSignal * 0.5);

// Sanity check: don't exceed 2.5 ATR
const stopDistance = Math.abs(entryPrice - structuralStop);
const maxStop = atrSignal * 2.5;

if (stopDistance > maxStop) {
  // Pullback too deep, skip trade
  return null;
}

const stopLossPrice = structuralStop;
```

### EMA Stack Persistence

**My Take (Medium Priority):**

**GPT's Take (Optional Improvement):**
- Mentioned as "freshness rule" / "pullback count filter"
- Suggested avoiding "pullback #7 in exhausted trend"

**Reconciliation:** Both are addressing trend quality, just different angles:
- **Stack persistence** = avoid entering right after crossover (my concern)
- **Pullback count** = avoid late-cycle entries (GPT's concern)

**Agreed Implementation:**
```typescript
// Phase 1: Stack persistence (anti-whipsaw)
function hasStableStack(ema8: number[], ema21: number[], ema55: number[], 
                        direction: 'long' | 'short', bars: number = 3): boolean {
  for (let i = 0; i < bars; i++) {
    const idx = ema8.length - 1 - i;
    if (direction === 'long' && !(ema8[idx] > ema21[idx] && ema21[idx] > ema55[idx])) {
      return false;
    }
    if (direction === 'short' && !(ema8[idx] < ema21[idx] && ema21[idx] < ema55[idx])) {
      return false;
    }
  }
  return true;
}
```
